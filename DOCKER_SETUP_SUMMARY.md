## 🔐 Security Considerations

For production deployment, you should:

1. **CORS**: Restrict `allow_origins` in `src/api/main.py`
   ```python
   allow_origins=["https://yourdomain.com"]
   ```

2. **Disable Reload**: Set `--reload` to false in backend
   ```dockerfile
   CMD ["uvicorn", "src.api.main:app", "--host", "0.0.0.0", "--port", "8000"]
   ```

3. **Environment Variables**: Use `.env` file
   ```bash
   API_HOST=0.0.0.0
   API_PORT=8000
   ```

4. **HTTPS**: Configure reverse proxy/load balancer

5. **Logging**: Add proper logging configuration

## 🆘 Troubleshooting

**Docker daemon not running:**
```bash
# Start Docker Desktop from Applications, or:
open /Applications/Docker.app
```

**Port already in use:**
```bash
# Change ports in docker-compose.yml and restart
docker-compose down
docker-compose up -d
```

**Rebuild everything:**
```bash
docker-compose down -v
docker-compose build --no-cache
docker-compose up -d
```
